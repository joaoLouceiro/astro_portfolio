Hey, there!

So you stumbled upon this page, and you're trying to figure out some more about who this person is, eh?

I'm João, and I have been developing software professionally as a Full Stack developer since 2018.

My journey into the world of programming started when I was just a kid, playing around with HTML and CSS, but it only got serious when I got in a Java bootcamp at Coimbra's University. You can read more about it at [Acertar o Rumo's web page](https://www.uc.pt/fctuc/dei/acertarorumo/). From there, I went on to work as a consultant for about 6 years, focusing on SAP BTP, SAP UI5 and Java/Spring.

I ended up leaving that position because I felt I wasn't being pushed enough on the technical side of things.

So for the past year I have been trying to push my limits.

I went deep into the Linux rabbit hole. I went from barely understanding what the fuss was about to running a multiple machine Arch/Ubuntu Server home lab.

I dabbed in quite a few different languages, from C to Lisp, passing by Python and Go.
